# Changelog
## 14.0.1
- Initial release, for Foundry VTT v13 and v14
- Chain icon showing at a glance whether a token is linked to its Actor — in Actor sheet headers, in the Token HUD (Gamemasters only) and in the Actors sidebar
- Left-click toggles the link, right-click opens the token or prototype token configuration, middle-click reveals the Actor in the sidebar
- A small `P` marks icons that target the Actor's prototype token
- Tooltips on every icon describing the current state and the available clicks
- Each of the three display locations can be switched off per user
- Optional clearer labels on the buttons of the Token and Prototype Token configuration, plus a confirmation before the prototype is overwritten
- System-agnostic; English and German localization
